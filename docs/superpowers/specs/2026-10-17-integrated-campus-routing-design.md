# 地面与地下距离导航设计（2026-10-17 修订）

此文替代原遮雨导航设计。所有导航只按距离，不再维护遮雨区域、天气权重、建筑边缘避雨、短露天阈值或换层附加代价。

- 地面保留现有统一栅格、八邻接 Dijkstra、端点/入口吸附和可走区域内拉直。
- `findIntegratedRoute(from, to, map, { connectorSnapMeters? })` 保留现有连接点对枚举；比较地面直达与一次「地面 → 地下 → 地面」候选的实际路径长度。同距保留地面，地下不可达回退地面。
- 不增加元图或新导航模式；不保证多次进出地下的全局最短距离。吸附、栅格离散化、拉直仍可能影响实际结果。
- 地面/地下入口保留已有导航与手绘维护语义。
- 长廊区域的 ID、名称、轮廓、parts、中心、介绍不变，作为普通服务区域；不再有专属遮雨属性、筛选或样式。
- 结果仅保留分层路径、距离、时间、地下距离和进出连接点提示。蓝色地面、紫色地下。

验证与迁移见 `../../distance-navigation.md`。
